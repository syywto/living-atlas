# 三张活地图 · 多模态大模型的视觉理解与推理

围绕图表问答，连接领域知识、研究生态与可核查的分析过程。当前版本 v0.8，包含 18 个条目、101 条有理由的关联。

## 在线浏览

在线网址：https://syywto.github.io/living-atlas/ 。发布工作流从 website-source.zip 中提取 docs 目录。可浏览三张地图、关联浮标、全文文档、来源、图片和教学练习。图表为自制教学数据，不是模型性能实验。成员贡献及真实互评尚未填录。

这是静态展示版，在线管理员编辑、服务端反馈与生成式 AI 不运行。管理员编辑在自己的电脑上完成，再导出并发布新版。

## 本地修改

1. 安装 Node.js 22 或更高版本，无需安装第三方依赖。
2. 下载并解压完整项目，双击“启动网站.cmd”。
3. 初次运行时自行设置管理员密码，在网站内编辑并保存。
4. 双击“导出展示版.cmd”，更新 docs 目录。
5. 运行 node scripts/package-public.mjs，将生成目录的内容压缩为 website-source.zip，替换仓库中的同名文件，等待自动发布。

也可以运行 node server.mjs 启动，运行 node scripts/export.mjs 导出。默认终端启动地址为 http://127.0.0.1:3000；Windows 启动器优先使用 3001，以实际提示为准。

## 文件说明

- public：网页与当前初始内容。
- docs：可直接发布的展示版及明确引用的教学附件。
- server.mjs、lib：本地验证、保存与编辑所需的服务代码。
- scripts：启动、导出与安全打包工具。
- tests：使用隔离数据的功能检查，可运行 node --test tests/*.test.mjs。
- uploads：本内容明确引用的公开教学图片和 CSV/TXT 附件。

密码、密钥、运行记录、实际反馈及修改历史不包含在本仓库。公开代码中的密码只出现在隔离测试用例，不是本站管理员密码。下载本项目不会获得原管理员权限，首次本地运行需要自行初始化。

## 发布设置

本仓库使用 GitHub Actions 发布。上传并替换根目录 website-source.zip 后，.github/workflows/pages.yml 会提取 docs 并部署；在 Actions 中查看 Publish Living Atlas 的结果。

页面资料的适用范围、出处和待核实事项以各条目说明为准。本校课程关联、真实模型实践与 AI 能力仍需真实材料，不以页面完整代替完成全部课程要求。
