# 三张活地图 · 多模态大模型的视觉理解与推理

以图表问答连接领域知识、研究生态和可核查的分析过程。当前 v0.7，18 个条目、101 条有理由的关联；包含交互地图、全文文档、原始来源、图片与教学练习。

网站地址由本仓库的 GitHub Pages 发布结果提供，可从右侧 Deployments / github-pages 进入。

## 下载与本地修改

下载本仓库中的 `website-source.zip` 并解压。它包含网页源码、当前初始内容、展示文件、本地编辑服务、启动与导出工具、测试，以及明确引用的三份教学图片和附件。

安装 Node.js 22 或更高版本后，双击“启动网站.cmd”，在自己的电脑上初始化管理员密码，即可在网页中编辑内容。无需安装第三方运行依赖。

## 更新公开网站

1. 在本地网站修改并保存。
2. 双击“导出展示版.cmd”，更新 `docs` 展示目录。
3. 整理新的公开源码包。只包含本项目的公开代码、初始内容、`docs` 与明确引用的教学附件；禁止放入 `.runtime`、`.env`、`data`、实际反馈、密码记录或修改历史。
4. 压缩包根目录应直接包含 `docs/index.html` 和 `docs/data.json`，不要再套一层外部文件夹。
5. 在仓库中上传并替换同名 `website-source.zip`，提交变更。
6. `.github/workflows/pages.yml` 自动提取压缩包的 `docs` 目录并发布。等 Actions 显示成功后刷新网站。

## 公开范围

网页、静态地图、文档、来源、图片及规则练习可以在线浏览。在线管理员编辑、共享反馈和生成式 AI 服务不在此静态站点运行；内容修改在本地完成后重新发布。

公开包不含原管理员密码或密码哈希、模型密钥、私有环境配置、实际反馈和历史记录。下载代码不会获得原管理员权限。测试用例中的示例密码仅用于隔离测试。

教学图表是自制练习数据，不代表模型性能实测。成员贡献及真实互评尚未填录，本校课程、真实模型实践和 AI 接入等仍需实际材料。各条目的事实、引用和适用边界以正文说明为准。
